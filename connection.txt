Displays the received text

4. Before switching on

Use a separate USB connection to power each Arduino.

Do not connect the two Arduino boards' GPIO pins together.

Aim the LED directly at the LDR, initially about 2–5 cm away.

Use the transmitter and receiver code from the previous message, with BIT_TIME = 250 in both programs.

If the received text is incorrect, adjust the LDR potentiometer and check whether DO goes LOW or HIGH when illuminated. Set LIGHT_ON_LEVEL accordingly in the receiver code.

Note: The LDR is slow, so this is a low-speed educational demonstration rather than a high-speed internet Li-Fi system.
